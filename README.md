# Cute 3D

RPG 3D com direção visual cute, desenvolvido no Godot.

**Leia primeiro:** [Bíblia do projeto](documentacao/BIBLIA_DO_PROJETO.md).

O arquivo de bíblia contém decisões, estado atual, marcos, testes e protocolo de continuidade para futuras sessões de desenvolvimento.

## Abrir
No Godot, clique em **Importar**, selecione `project.godot` e abra o projeto.

## Local do projeto no Mac
`/Volumes/Extreme SSD/MEUS JOGOS/Godot/Cute 3D`
